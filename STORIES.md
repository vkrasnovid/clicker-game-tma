# Stories: Кликер — Telegram Mini App

## Story 1: Основной тап-механизм
**Описание:** Центральный элемент для тапа (монета/кристалл), счётчик очков, визуальная обратная связь при тапе (+1 летит вверх), анимация нажатия.
**Acceptance criteria:**
- [ ] Тапаемый элемент по центру экрана (большая монета/кристалл)
- [ ] Каждый тап = +N очков (N зависит от апгрейдов)
- [ ] Анимация: "+N" текст вылетает вверх с fade out
- [ ] Анимация нажатия (scale bounce)
- [ ] Счётчик очков сверху (большой, с форматированием: 1.2K, 3.5M)
- [ ] 60fps, без лагов при быстром тапе
**Агент:** developer-frontend
**Приоритет:** P1
**Оценка:** 2 часа

## Story 2: Магазин апгрейдов
**Описание:** Панель с апгрейдами: увеличение дохода за тап, автокликер (пассивный доход), множитель. Каждый апгрейд дорожает при покупке.
**Acceptance criteria:**
- [ ] Минимум 6 апгрейдов:
  - Сила тапа (Tap Power): +1 за тап → +2 → +5...
  - Автокликер (Auto Clicker): +N/сек
  - Множитель (Multiplier): x2, x3...
  - Критический тап (Critical Tap): шанс x10
  - Мега тап (Mega Tap): каждый 50-й тап = x100
  - Золотая лихорадка (Gold Rush): 10 сек всё x5
- [ ] Цена растёт экспоненциально: base * 1.15^level
- [ ] Кнопка покупки неактивна если не хватает монет
- [ ] Уровень каждого апгрейда отображается
- [ ] Панель скроллится если апгрейдов больше чем помещается
**Агент:** developer-frontend
**Приоритет:** P1
**Оценка:** 3 часа

## Story 3: Пассивный доход + офлайн прогресс
**Описание:** Автокликер приносит доход каждую секунду. При возвращении в игру начисляется офлайн-доход (до 2 часов).
**Acceptance criteria:**
- [ ] Автокликер тикает каждую секунду
- [ ] Отображение дохода в секунду ("X/сек")
- [ ] При закрытии сохраняется timestamp
- [ ] При открытии — начисление офлайн-дохода (макс 2 часа)
- [ ] Попап "Вы заработали X монет пока отсутствовали"
- [ ] Все данные в localStorage
**Агент:** developer-frontend
**Приоритет:** P1
**Оценка:** 2 часа

## Story 4: Визуальная прогрессия + prestige
**Описание:** Фон и элементы меняются при достижении вех. Система prestige: сброс прогресса за постоянный бонус.
**Acceptance criteria:**
- [ ] 5 визуальных этапов (меняется фон, цвет монеты):
  - Бронза (0-1K)
  - Серебро (1K-100K)
  - Золото (100K-10M)
  - Платина (10M-1B)
  - Алмаз (1B+)
- [ ] Prestige: сброс за "кристаллы" (перманентный множитель)
- [ ] Prestige доступен от 1M очков
- [ ] Кристаллы = log10(score) при prestige
- [ ] Множитель: 1 + кристаллы * 0.1
**Агент:** developer-frontend
**Приоритет:** P2
**Оценка:** 2 часа

## Story 5: Telegram Mini App интеграция
**Описание:** TMA SDK, haptic feedback, share результатов, тема Telegram.
**Acceptance criteria:**
- [ ] Telegram WebApp SDK подключен
- [ ] Haptic feedback при тапе (light) и при покупке (medium)
- [ ] Кнопка "Поделиться" — отправить счёт в чат
- [ ] Тема подстраивается под Telegram (dark/light)
- [ ] Fallback для работы в браузере
**Агент:** integrator
**Приоритет:** P1
**Оценка:** 1 час

## Story 6: Дизайн и polish
**Описание:** Красивый UI, частицы при тапе, плавные анимации, звуковые эффекты (опционально).
**Acceptance criteria:**
- [ ] Частицы при тапе (золотые искры)
- [ ] Плавные CSS-анимации на кнопках магазина
- [ ] Прогресс-бар до следующего визуального этапа
- [ ] Статистика: всего тапов, всего заработано, время в игре
- [ ] Все тексты на русском
- [ ] Тёмная тема по умолчанию
**Агент:** developer-frontend
**Приоритет:** P2
**Оценка:** 2 часа

## Story 7: E2E тестирование
**Описание:** Полный прогон: тап → покупка апгрейда → автокликер → офлайн доход → prestige → share.
**Acceptance criteria:**
- [ ] Тап работает (touch + mouse)
- [ ] Апгрейды покупаются, цена растёт
- [ ] Автокликер тикает
- [ ] Офлайн доход начисляется
- [ ] Prestige сбрасывает и даёт бонус
- [ ] Share работает в Telegram
- [ ] Данные сохраняются между сессиями
**Агент:** tester
**Приоритет:** P1
**Оценка:** 1 час

---

**Итого:** 7 stories, ~13 часов
